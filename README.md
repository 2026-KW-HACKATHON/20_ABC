# 월계온 (Wolgye-ON)

월계1동 생활 지도 앱입니다. 기능은 네 가지입니다.

- **소식**: 광운대 공지사항, 서울시 문화행사, 노원구청 주요행사계획을 자동으로 모으고, 관리자가 승인하면 앱에 올라갑니다. 한 장소에 행사가 여럿이면 핀 하나로 묶고, 누르면 진행 중인 행사부터 목록으로 보여줍니다. 지도 핀, 달력, 내 일정(즐겨찾기), 후기를 지원합니다.
- **길찾기**: 캠퍼스 관통로·끊긴 길·광장·주차장까지 쓰는 **지름길**, 공식 보행로만 쓰는 **일반 경로**, 계단과 급경사를 피하는 **배리어프리 경로**가 있습니다. 공사 구간은 피해 가는 경로로 다시 계산할 수 있고, 쪽문 개방 시간도 반영합니다. 메모를 적으면 들를 가게와 순서를 정해주고 근처에 가면 알려줍니다.
- **행사 제보**: 구청·서울시 사이트에 없는 작은 동네 행사(아파트 장터, 경로당 잔치, 바자회 등)를 주민이 제보합니다. 포스터 사진을 올리면 AI(Gemini 무료 API 또는 Claude API)가 이름·일시·장소를 미리 채웁니다. 관리자가 승인하면 지도에 올라가고, 결과는 제보자에게 앱 알림으로 갑니다.
- **관리자 화면**(`/admin`): 행사 승인·등록(주민 제보 포함), 길 제보 검토, 공사 구간 등록, 지도 데이터 갱신을 합니다.

**화면**: 지도 위 검색창·분류 필터(전체/문화·예술/학술·교육/지역·참여/음악·장터 등 세부 종류, ☰에서 종류별 숨기기)·범례, 분류 색 + 종류 아이콘 핀, 위성 지도 전환, 월계1동 안에서는 곧 열리는 행사를 돌아가며 보여주는 실시간 보드, 행사 상세(기간·시간·위치, #행사 소개, #참여방법, 후기·사진·동영상, 캘린더 추가·공유), MY 대시보드(프로필·즐겨찾기·알림·행사 제보·설정).

로그인 없이 지도, 행사, 길찾기를 쓸 수 있습니다. 행사 제보, 후기, 길 제보, 즐겨찾기, 달력 메모 저장은 로그인이 필요합니다. 알림은 **앱 안에서만** 보냅니다(문자·카톡 없음).

```
wolgyeon/
├─ server/          FastAPI 서버 (API, DB, AI 연결, 행사 수집, 지도·경로 데이터)
│  ├─ app/          서버 코드
│  ├─ app/seed/     월계1동 OpenStreetMap 데이터 (기본값)
│  ├─ tools/        지도·고도 데이터 갱신 명령
│  ├─ tests/        오프라인 테스트 (python -m pytest -q)
│  ├─ run.bat       윈도우용 실행 (기숙사 PC)
│  └─ run.sh        맥·리눅스용 실행
├─ web/             모바일 웹앱 + 관리자 화면 (서버가 함께 제공)
├─ android/         안드로이드 앱 (WebView로 서버 주소를 여는 앱)
├─ Dockerfile       클라우드 배포용
└─ render.yaml      Render 무료 배포 설정
```

## 1. 내 컴퓨터에서 바로 실행해보기

Python 3.10 이상이 필요합니다.

> **보안 안내**: `server/.env.example`은 실제 API 키와 관리자 비밀번호가 들어갈 수 있는 파일이라 **GitHub 저장소에서 제외**했습니다(`.gitignore`). 저장소를 받은 뒤에는 아래 변수 이름을 참고해서 `server/.env` 파일을 직접 만드세요. API 키와 비밀번호는 `.env`에만 적고, 저장소에 올리지 마세요.
>
> | 변수 | 설명 |
> |---|---|
> | `ADMIN_USERNAME`, `ADMIN_PASSWORD` | 관리자 대시보드 로그인 정보 |
> | `GEMINI_API_KEY`, `GEMINI_MODEL` | 포스터 읽기·키워드 생성용 Gemini (무료) |
> | `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL` | Claude 사용 시 (선택) |
> | `AI_PROVIDER` | `gemini` 또는 `anthropic` |
> | `SEOUL_API_KEY` | 서울 열린데이터광장 인증키 (없으면 샘플 5건) |
> | `DATABASE_URL` | 비워두면 SQLite 파일 사용, PostgreSQL(Neon) 주소 |
> | `SECRET_KEY` | 로그인 토큰 서명용 임의의 긴 문자열 |
> | `KAKAO_REST_KEY`, `VWORLD_KEY` | 장소 검색, 국내 위성영상 (선택) |
> | `COLLECT_INTERVAL_HOURS`, `COLLECT_ON_START`, `SEED_SAMPLE` | 자동 수집 주기, 시작 시 수집 여부, 예시 행사 사용 여부 |

```bash
cd server
# server/.env 파일을 새로 만든 뒤 (윈도우: 메모장으로 server\.env 생성) ADMIN_PASSWORD 만 정해도 실행됩니다 (API 키는 나중에)
./run.sh                    # 윈도우: run.bat 더블클릭
```

- 앱: http://localhost:8000
- 관리자: http://localhost:8000/admin (`.env`에 적은 ADMIN_USERNAME / ADMIN_PASSWORD로 로그인)
- API 문서: http://localhost:8000/docs

> 휴대폰 위치와 카메라는 **https 주소나 localhost에서만** 동작합니다. 휴대폰으로 시험하려면 아래 2번이나 3번처럼 https 주소를 만드세요.

## 2. API 키 받기

`.env`(또는 클라우드 환경변수)에 넣습니다.

| 이름 | 어디서 | 없으면 |
|---|---|---|
| `GEMINI_API_KEY` (무료) | [Google AI Studio](https://aistudio.google.com/apikey) → Create API key. 결제 등록 없이 무료 등급으로 쓸 수 있습니다 | 행사 제보 포스터를 자동으로 읽지 않고(직접 입력), 광운대 공지는 규칙 기반으로 일시·장소를 추출하고, 구청 PDF 자동 추출은 쓸 수 없습니다 |
| `ANTHROPIC_API_KEY` (선택) | [console.anthropic.com](https://console.anthropic.com) → API Keys (유료) | Gemini 대신 Claude를 쓰고 싶을 때만 |
| `SEOUL_API_KEY` | [서울 열린데이터광장](https://data.seoul.go.kr) 회원가입 → 인증키 신청(일반) | `sample` 키로 5건만 받아옵니다 |
| `DATABASE_URL` | [Neon](https://neon.tech) 무료 프로젝트 → Connection string | SQLite 파일(`server/data/wolgyeon.db`)을 씁니다 |

**AI 선택**: `GEMINI_API_KEY`와 `ANTHROPIC_API_KEY` 중 하나만 넣으면 그쪽을 씁니다. 둘 다 넣으면 Gemini를 쓰고, `AI_PROVIDER=anthropic`으로 바꿀 수 있습니다.

**Gemini 무료 등급 주의**
- 기본 모델은 `gemini-3.5-flash-lite`입니다(`GEMINI_MODEL`로 변경). 무료 등급의 분당·하루 호출 한도는 [AI Studio](https://aistudio.google.com)에서 확인하세요. 한도를 넘으면 앱은 "내용을 직접 적어주세요"로 넘어가고, 제보는 정상 접수됩니다.
- Google 안내에 따르면 **무료 등급으로 보낸 내용은 Google 제품 개선에 쓰일 수 있습니다.** 그래서 행사 제보 화면에 "사진이 AI 서비스로 전송된다"는 안내를 넣어두었습니다. 실서비스로 오래 운영하려면 유료 등급(결제 등록)으로 바꾸는 편이 안전합니다.
- 포스터 읽기는 사용자당 하루 20회로 제한돼 있습니다(`routers/tips.py`의 `DAILY_AI`).

Claude를 쓰면 기본 모델 `claude-haiku-4-5-20251001` 기준으로 포스터 한 장에 약 3~5원이 듭니다.

## 3. 무료 클라우드에 올리기 (Render + Neon)

1. 이 폴더를 GitHub 저장소에 올립니다. `.gitignore`가 `.env`와 `data/`를 제외합니다.
2. [Neon](https://neon.tech)에서 무료 PostgreSQL을 만들고 연결 주소를 복사합니다. Render 무료 서버는 재시작하면 파일이 지워져서 SQLite로는 데이터가 사라집니다.
3. [Render](https://render.com) → **New → Blueprint** → 저장소 선택. `render.yaml`이 자동으로 읽힙니다.
4. 환경변수 `ADMIN_PASSWORD`, `GEMINI_API_KEY`, `SEOUL_API_KEY`, `DATABASE_URL`을 채우고 배포합니다.
5. `https://<서비스이름>.onrender.com`이 앱 주소입니다.

Render 무료 플랜은 15분 동안 접속이 없으면 잠들고, 다시 깨어나는 데 30~60초가 걸립니다. 잠든 동안에는 행사 자동 수집도 멈춥니다(관리자 대시보드의 **지금 수집** 버튼은 언제든 쓸 수 있습니다). **발표와 전시 기간에는 기숙사 PC로 운영하거나, 시작 전에 한 번 접속해서 깨워두세요.**

## 4. 기숙사 PC로 옮기기

1. PC에 Python을 설치하고 이 폴더를 복사합니다.
2. `server/.env`를 채웁니다. `DATABASE_URL`을 비워두면 PC의 SQLite 파일에 저장됩니다. Neon 주소를 그대로 두면 클라우드에서 쓰던 데이터를 이어서 씁니다.
3. `server/run.bat`을 실행합니다.
4. 밖에서 https로 접속할 수 있게 **Cloudflare Tunnel**을 씁니다(무료, 공유기 설정 불필요).
   ```
   cloudflared tunnel --url http://localhost:8000
   ```
   출력되는 `https://xxxx.trycloudflare.com`이 앱 주소입니다. 이 임시 주소는 실행할 때마다 바뀝니다. 주소를 고정하려면 Cloudflare에 도메인을 연결하고 *named tunnel*을 만드세요. 안드로이드 앱에 넣을 주소가 바뀌지 않아야 하기 때문입니다.
5. PC가 절전 모드로 들어가지 않게 설정하세요.

## 5. 안드로이드 APK 만들기

1. `android/gradle.properties`의 `wolgyeonServerUrl`을 배포한 https 주소로 바꿉니다.
2. Android Studio → **Open** → `android` 폴더 → Gradle Sync.
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. 배포용은 **Generate Signed Bundle / APK**를 씁니다.

앱은 서버의 웹앱을 여는 구조라서 **화면이나 기능을 고쳐도 APK를 다시 만들 필요가 없습니다**(서버만 다시 배포하면 됩니다). 앱이 직접 처리하는 것은 위치 권한, 카메라 촬영과 갤러리 선택, 뒤로가기, 외부 링크를 브라우저로 열기, 오프라인 화면입니다.

> 이 저장소를 만든 환경에서는 Android SDK를 받을 수 없어서 APK 빌드까지는 확인하지 못했습니다. 코드는 AGP 8.7.3, Gradle 8.10.2, Kotlin 2.0.21, compileSdk 35 기준으로 작성하고 검토했습니다.

## 6. 처음 운영할 때 할 일

1. `/admin` 로그인 → **사용자** 메뉴에서 팀원 계정에 관리자 권한을 줍니다(팀원이 앱에서 먼저 가입해야 합니다).
2. **지도 데이터 → 고도 받기**를 누릅니다. 배리어프리 경로에 경사도가 반영됩니다(1~2분).
3. **대시보드 → 지금 수집** → **행사 승인**에서 날짜·장소·지도 위치를 확인하고 승인합니다. 예시 행사 2개는 삭제하거나 `.env`에서 `SEED_SAMPLE=0`으로 끕니다.
4. 앱의 **길찾기 → 길 정보 제보**로 팀원들이 아는 샛길, 아파트 후문·쪽문(개방 시간 포함), 막힌 길을 그립니다. 관리자 계정으로 그리면 바로 반영됩니다.

## 7. 지름길은 어떻게 만들어지나 (발표용)

보행 그래프는 OpenStreetMap 월계1동 데이터(노드 약 11,500개, 간선 약 17,000개)로 만들고, 여기에 다음을 더합니다.

| 종류 | 방법 |
|---|---|
| 캠퍼스·학교 내부 | 일반 경로에서는 빼고 지름길에서는 허용 |
| 끊긴 길 연결 | 8m 안의 막다른 길 끝을 연결 (건물·담장을 뚫지 않을 때만) |
| 광장·공원·평면주차장 가로지르기 | 건물·담장에 막히지 않는 110m 이내 직선 |
| 주민 길 제보 | 새 길·쪽문(개방 시간)·막힌 길·계단·가파른 길 → 관리자 승인 후 반영 |
| 공사 구간 | 관리자 등록 → "피해서 가기" |
| 경사도 | Open-Meteo 고도(90m 격자) → 5.6%(법정 접근로 기준 1/18) 초과 구간 회피, 8.3% 초과는 배리어프리에서 제외 |

경로는 휴대폰에서 다익스트라로 계산합니다.

**정확도의 한계**: OSM에 없는 길은 찾지 못하고, "가로지르기"는 화단이나 낮은 턱을 모릅니다. 시연할 경로는 미리 걸어보고 확인하세요. 틀린 곳은 길 제보로 고치면 됩니다. 이 구조 자체가 "주민 제보가 쌓일수록 정확해지는 지도"라는 발표 포인트입니다.

## 8. 개인정보

- 가입할 때 아이디, 닉네임, 비밀번호만 받습니다(전화번호·이메일 없음). 비밀번호는 PBKDF2로 해시해 저장합니다.
- 행사 제보 포스터는 EXIF(촬영 위치 등) 정보를 지우고 저장합니다. 승인 전에는 관리자만 볼 수 있고, 제보자 이름·연락처는 공개되지 않습니다.
- 비밀번호를 바꾸거나 탈퇴하면 기존 로그인 토큰은 무효가 됩니다.

## 10. 지도 범위와 지도 데이터 새로 받기

- **지도·일반 도보 길찾기**: 월계동(월계1·2·3동) 안. 바깥은 흐리게 보이고 지도도 그 밖으로는 안 움직입니다.
- **지름길·편한 길 찾기(배리어프리)·길 제보**: 점선으로 표시된 월계1동 안.
- **행사 제보**: 월계동 안에서 열리는 행사.
- 범위는 지도 데이터에 들어 있는 `월계N동` 행정경계로 정해집니다. 월계1동 경계만 있으면 월계1동이 범위가 됩니다.

**가장 쉬운 방법**: 관리자 화면 → 지도 데이터 → "OSM 지도 새로 받기 · 지금 받기" (서버가 직접 받음, 1~3분).

**직접 받는 방법** (서버에서 접속이 안 될 때)
1. https://overpass-turbo.eu 접속
2. 왼쪽 편집창을 비우고 `server/tools/overpass_wolgye.txt` 내용을 붙여넣기
3. 위쪽 "실행" → 끝나면 "내보내기" → "GeoJSON" → 다운로드 (`export.geojson`)
4. 관리자 화면 → 지도 데이터 → "GeoJSON 파일로 교체"에 올리기
5. 결과의 `area`에 `["월계1동","월계2동","월계3동"]`이 보이면 성공. 이어서 "고도 받기"를 한 번 눌러 경사도를 다시 계산하세요.

## 11. 구청 행사 자료

## 12. 이번에 추가된 것 (요약)

- **AI 빈칸 채우기**: 관리자 → 행사 편집 "✦ AI로 빈칸 채우기"(제안만, 확인 후 저장) / 대시보드 "AI로 행사 빈칸 채우기"(한 번에 20개 저장). 새로 수집된 행사는 자동. 원문 링크가 있을 때만 날짜·장소·요금을 채우고, 원문이 없으면 소개만 정리합니다.
- **위성 지도**: 기본은 Esri 위성영상(키 없음). `.env`에 `VWORLD_KEY`(국토부 브이월드)를 넣으면 국내 고해상도 영상으로 바뀝니다.
- **후기 사진·동영상**: 후기 하나에 4개까지, 사진은 1600px로 줄이고 촬영 위치(EXIF)를 지움, 영상은 30MB 이하(`MAX_VIDEO_MB`). 파일은 `server/data/media/reviews/`.
- **계단·가파른 길 칠하기 제보**: 손가락으로 칠한 범위(붓 반지름 5·8·12m)를 지나는 경로 구간을 계단·급경사로 표시 → 배리어프리 경로가 피해 감.
- **길찾기 화면**: 경로가 나오면 위 패널이 접히고 출발·도착·경로 종류가 아래 창으로 이동. 아래 창은 끌어내리면 윗줄만 남고 다시 끌어올리면 펼쳐짐. "내 위치" 버튼으로 출발지 지정(위치를 알면 자동).


## 13. 월계동 중심 표시 · 검색 · 달력 메모
- **지도·달력·목록에는 월계동(1·2·3동) 안 행사만** 나옵니다 (`/api/events?area=1`). 월계동 밖이거나 위치가 없는 행사는 **검색**(`/api/events/search`)에서만 '월계동 밖' 표시와 함께 나옵니다.
- **위치 자동 찾기**: 좌표 없이 들어온 행사(구청 PDF 등)는 장소 이름을 지도(OSM) 이름과 맞춰 위치를 넣습니다. 예: '월계도서관 4층' → 월계문화정보도서관. 서버를 켤 때·수집 후·구청 자료를 올린 뒤 자동으로 실행되고, 관리자 대시보드의 '장소 이름으로 위치 찾기'로도 실행됩니다. 별칭은 `server/app/services/places.py`의 `ALIASES`에 추가합니다.
- **연관어 검색**: '아이' → 어린이·유아·가족·그림책… 처럼 연관어 사전(`services/search.py`의 `CONCEPTS`)과 세부 종류로 넓혀 찾습니다. AI 키가 있으면 관리자 'AI 검색 키워드 만들기'로 행사마다 연관 키워드를 붙여 더 잘 찾습니다(수집 후 자동으로도 30개씩).
- **달력**: 1주일 미만 행사만 날짜에 점으로, 1주일 이상 이어지는 전시·강좌는 '이번 달 계속 이어지는 행사'에 따로 모읍니다. 날짜를 누르면 **내 메모**를 적을 수 있습니다(로그인: 계정에 저장, 손님: 이 기기에 저장 → 로그인하면 계정으로 옮겨짐).
- 행사 상세의 **캘린더** 버튼은 월계온 달력의 그 날짜로, **자세히 알아보기**는 원문 안내 페이지로 이동합니다.
- 관리자 대시보드의 **'승인 대기 행사 한 번에 공개'**(전체 / 월계동 안만)나 '행사 승인'의 **'대기 전체 승인'**으로 대기 행사를 한꺼번에 공개할 수 있고, **월계동 안/밖** 거르기, **여러 개 골라 승인**도 됩니다. 위치가 없어도 승인할 수 있으며 그 행사는 검색에서만 보입니다.
- 아래 메뉴: 지도 · 소식 · 길찾기 · **검색** · MY. 길찾기 모드 이름은 지름길 / 일반 도보 / **편한 길 찾기(배리어프리)**.
- **실시간 내 위치**: 위치를 한 번 허용하면 2초마다 지도 위 파란 점만 옮깁니다(지도는 움직이지 않음, 앱이 뒤로 가면 멈춤). 오차가 15m 넘으면 옅은 원으로 범위를 보여줍니다.
- **버튼 효과음**: Kenney "Interface Sounds"(CC0, `web/sfx/CREDITS.txt`). 지도 설정(☰)이나 MY → 설정에서 끌 수 있습니다.
- 메모 경로(메모로 길 찾기) 기능은 제거했습니다.
- **앱 설치 안내**: 만든 APK를 `server/data/download/wolgyeon.apk`로 넣어 두면, 웹으로 들어온 안드로이드·PC 사용자에게 내려받기 안내가 뜹니다(파일이 없으면 안 뜸, '나중에'는 3일간 숨김). 아이폰에는 '홈 화면에 추가' 안내가 뜨고, 앱 안에서는 뜨지 않습니다.
- **아이폰 위치**: https 주소에서만 위치를 줍니다. 정밀 위치가 실패하면 일반 위치로 다시 시도하고, 권한이 꺼져 있으면 설정 경로를 안내합니다.
- **다크 모드·설정**: MY → 설정에서 화면 모드(기기 설정대로/밝게/어둡게), 효과음 켜기·크기, 알림(휴대폰 알림·근처 행사 추천·즐겨찾기 행사 알림 시간·새 행사 분류)을 바꿀 수 있습니다. 설정은 로그인하지 않아도 열립니다.
- **휴대폰 알림(안드로이드 앱)**: 앱이 약 1분마다(절전 중에는 더 늦게) `/api/app/feed`를 확인해 ① 즐겨찾기 행사 곧 시작(설정한 시간 전) ② 관리자 공지 ③ 근처 행사 추천(하루 한 번, 10~20시)을 휴대폰 알림으로 띄웁니다. Firebase 없이 동작합니다.
- **관리자 → 모두에게 알림 보내기**: 즐겨찾기 행사 알림(n시간 안), 행사 추천(문구 자동), 직접 쓰기. **APK 올리기**도 대시보드에서 합니다.
- **바로 뜨는 알림**: 앱·웹 화면을 보고 있으면 15초마다 확인해, 관리자가 보낸 알림을 화면 위쪽 카드로 바로 보여줍니다.
- **즐겨찾기 표시**: 즐겨찾기한 행사 핀(묶음 핀 포함) 오른쪽 위에 작은 하트가 붙습니다. 후기는 시작 전 행사에도 남길 수 있습니다.
